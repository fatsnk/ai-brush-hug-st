# 灵画师

一款对萌新友好的生图扩展插件，愿世间充满和平友爱~

灵画师是 SillyTavern 生图扩展，提供 NovelAI、OpenAI 兼容和 ComfyUI 接口配置、生图工坊、聊天配图、画师串库、角色档案、绘图管理、历史版本和九套人物主题。

## 安装

在酒馆「扩展 → 安装扩展」中填入：

```text
https://github.com/ibome/ai-brush-hug-st
```

刷新页面，在扩展设置中打开「灵画师」，或点击透明人物悬浮图标。

需要 SillyTavern 1.12.13 或更高版本。仓库已包含构建好的 `dist/`，普通用户无需安装 Node 依赖或编译源码。

## 服务器组件

持久化生图任务、酒馆服务器存图、跨设备参考素材和服务器聊天关联需要安装 `linghuashi-storage` 服务器组件。它仅访问登录账号自身的数据。

管理员下载 Releases 中的 `linghuashi-storage-v版本.zip`，将包内 `linghuashi-storage` 目录放到酒馆的 `plugins/` 下，在 `config.yaml` 中启用：

```yaml
enableServerPlugins: true
```

重启酒馆。插件设置的「版本与更新」可检查前后端版本是否匹配。

组件目录可选放置 `allowed-accounts.json`，限制允许使用的账号：

```json
["default-user"]
```

不放这个文件时，所有已登录账号均可使用各自的存储。更新不应覆盖已有允许账号列表。完整步骤见 [安装与更新](docs/install.md)。

## 功能

- NovelAI：官方及已适配的第三方连接、参数预设、Vibe、V4.5 人物参考、图生图和蒙版局部重绘。
- OpenAI 兼容：地址规范化、模型列表、`nai-diffusion` 模型独立负面词、显式启用图片编辑。
- ComfyUI：API 工作流、参数映射、模板、LoRA、底图与蒙版上传、进度与结果读取。
- 聊天联动：识别 `image###提示词###`，在原提示词位置显示图片；提示词助手与智能配图。
- 多角色档案、画师串库和多接口命名配置。
- 绘图管理：收藏、筛选、参数回填、图片 ZIP 导入导出、单图编辑与历史版本。
- 备份与迁移：配置备份、完整备份、按条目分享包、加密秘钥、导入预览、合并与覆盖、配置撤回。

模型能力取决于所接服务。NovelAI 高级能力已实测部分官方与第三方组合；ComfyUI 和 OpenAI 图片编辑仍应以使用者实际工作流和接口验收为准。

## 备份

打开「插件设置 → 备份与迁移」：

1. 选择配置备份、完整备份或分享包，勾选内容。
2. 个人备份可勾选「包含秘钥并加密整个备份」，填写至少八个字符的密码。生成 `.lhbackup` 文件；不含秘钥时生成 ZIP。
3. 在目标设备选择备份文件，核对预览，选择合并库项目或覆盖所选配置，再确认恢复。

配置备份也会包含配置引用的底图、蒙版和 Vibe 素材。完整备份额外包含所选存储位置的图片、版本、收藏、聊天关联和任务归档。单包上限 200 MB。

合并保留当前参数与开关，同名但内容不同的库项目另存。覆盖只替换勾选的配置，不删除已有图片。可撤回上次配置恢复，导入的图片和素材仍保留。

秘钥采用 PBKDF2-SHA256 与 AES-256-GCM 加密；密码不会保存。分享包排除秘钥、接口凭据和聊天关联。没有包含秘钥的个人备份会尝试保留目标设备同类、同地址连接的现有秘钥；其他连接需重新填写。

任务以归档记录恢复，可载入参数后手动生图。正在执行的远程任务、其未保存响应和酒馆聊天正文不在迁移范围内。跨酒馆恢复聊天图片前，需要原角色卡、聊天和消息分支仍存在。详见 [备份与恢复](docs/backup.md)。

## 更新与回退

先导出个人备份，再用酒馆扩展管理中的更新入口更新前端。需要服务器组件时，同步更新它并重启酒馆。

「插件设置 → 版本与更新」提供版本查询、安装仓库和发布历史。旧版本安装包及 SHA256 校验文件在 Releases 中提供。配置结构升级后回退代码，需同时恢复升级前对应版本的配置备份。

## 开发

```sh
npm ci
npm test
npm run dev
npm run build:extension
npm run package:release
```

源码位于 `src/`，后端位于 `server/linghuashi-storage/`。发布产物生成到 `.release-artifacts/`，打包只读取明确列出的源码、文档和构建文件，排除账号数据、秘钥和允许账号列表。

不依赖原参考项目的源码；参考其功能流程，使用灵画师自身结构实现。
