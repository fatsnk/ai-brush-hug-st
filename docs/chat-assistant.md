# 聊天联动与提示词助手

[返回教程目录](../README.md)

聊天联动有两条路径：识别回复里已经写好的提示词，或由文字助手先分析画面再准备提示词。两者共用图片接口与任务队列。

## 标签生图

默认格式：

```text
角色推开窗户。image###1girl, opening a window, morning light, anime illustration###
```

1. 在角色设定、系统提示或你使用的酒馆预设里，约定让模型按这个格式写画面提示词。
2. 配好图片接口，启用插件设置中的「自动生图」。
3. 等角色新回复完整结束。插件识别标签后，将其保存为关联该会话、消息和回复分支的任务。
4. 「生成前确认提示词」开启时先核对草稿，关闭时直接入队。
5. 生成期间显示主题小人和阶段，成功后在原标签位置显示图片。

同一条消息可有多个标签，每个标签分别关联图片。不会自动绘制用户消息、尚未完成的流式片段或打开时的历史消息。只更改触发格式设置不会自动修改你的酒馆提示词。

关闭「在聊天中显示图片」只恢复标签原文，作品仍在绘图管理。关闭插件也会恢复原文；再次开启或刷新后可按已有记录恢复显示。

## 手动给一条回复配图

点击角色回复上的「给这条配图」：

- 已有标签：选择尚未生成的标签，提交绘图。
- 没有标签：先准备智能配图草稿，检查画面与提示词，再决定是否绘图。

手动入口可以处理旧消息。插件不会因为刷新而自动补画整段历史，避免重复提交。

## 聊天图片快捷操作

| 操作 | 结果 |
| --- | --- |
| 点击图片 | 打开大图、参数与历史版本。 |
| 再画一张 | 沿用本图参数，用新随机种子重新采样，保存为同图组的新版本。 |
| 修改提示词 | 修改本图的正向／支持的负面词后重画，不改全局提示词。 |
| 收藏、下载 | 收藏作品，或下载原图。 |
| 更多菜单 | 复制提示词、导入参数、完整编辑、图生图、局部重绘、图片增强或绘图管理。 |

无种子参数的 OpenAI 模型按原参数重新采样；ComfyUI 随机重画需要种子映射。重画期间旧图保留，可在聊天内切回旧版本。完整编辑类操作需要当前存储位置能访问原图。

## 提示词助手

入口：「提示词助手」。

1. 配好下方的文字模型来源。
2. 在「输入描述或提示词」写中文画面，或点「读取当前提示词」。
3. 选提示词模板及英文标签／英文自然语言等输出格式。
4. 点「生成提示词」「翻译」或「润色」。
5. 检查生成的画面、正向、负面和角色信息，可继续手动编辑。
6. 「载入生图参数」只填参数；「生成图片」才进入图片任务。

模型可能理解错误，生成后的草稿可以先用中文标签库或可视化编辑修正。界面说明无需配图时，也可核对理由后手动调整。

### 跟随酒馆

使用酒馆当前文字接口和采样配置。文字模型留空时跟随当前模型；可点刷新获取可用模型，独立选一个用于助手，不改变酒馆正文模型。

独立选模需要酒馆聊天补全接口支持；不提供模型查询的来源会尽量读取酒馆现有选项。正文正在生成时，先等待结束再使用跟随助手。

### 独立 API

填写 OpenAI 兼容文字接口地址、Key 和文字模型。接受根地址、带或不带 `/v1`、末尾 `/` 及支持的完整接口地址。

独立文字 API 可自动继承「接口配置」里的 OpenAI 图片连接；图片连接尚未配置时，也可用已填写的独立文字连接补齐。地址与 Key 成对同步，两边原本已有不同配置时保留各自设置。文字模型和图片模型分别选择，接口共用不等于模型共用。

最大输出 Token 默认 **4000**，界面可调整至 256 至 8192；另有温度与超时设置。独立接口需要允许浏览器访问。

## 智能配图

手动可点击「当前消息配图」，或在无标签的回复上点「给这条配图」。

助手读取截至目标消息的最近聊天；可选择参考角色卡、世界书和固定外貌，按设定的消息数与字符上限准备画面。世界书使用酒馆的相关条目扫描，插件不修改聊天正文。

流程是：读取上下文 → 判断画面 → 返回画面与英文提示词 → 人工检查／保存草稿 → 提交图片任务。多角色外貌和服装可来自角色档案。

自动化有两个独立开关，默认都关闭：

| 开关 | 开启后的行为 |
| --- | --- |
| 自动准备配图提示词 | 在新完成的角色回复后调用文字助手，准备画面草稿。 |
| 准备后自动生图 | 草稿准备好且符合配图条件后，继续提交图片生成。 |

推荐先只开启自动准备，检查一段时间的草稿质量，再决定是否自动生成。还可选按剧情判断、每条新回复或每隔几条回复，设置特写／全身／环境、张数和画幅。

已有生图标签的消息继续走标签流程。自动配图不补画问候、历史消息或被停止的回复；草稿和“不配图”的判断会记录，刷新不自动重新调用文字模型。

## 消息变化与取消

切换聊天、改原文或换回复分支后，尚未提交的聊天生图会取消。已被图片服务接收的任务继续取图和保存，回到原会话和分支后可显示对应结果。

助手失败或超时不自动重试。跟随酒馆的某些请求取消后只丢弃结果，底层文字请求可能继续完成；不会调用酒馆的全局停止去影响正文。任务恢复见 [绘图管理与任务](gallery-tasks.md)。
