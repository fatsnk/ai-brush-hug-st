# 常见问题

[返回教程目录](../README.md)

## 测试连接成功，为什么仍然无法生图？

连接测试、模型列表和图片生成是不同权限。先用一个明确支持的图片模型、小尺寸、一张图实际测试，再看服务返回的具体错误。检查额度、图片权限、模型名、尺寸和第三方参数。

「生图权限尚未验证」表示尚未通过实际图片请求验证，不要求额外点击一个隐藏的授权按钮。

## 获取模型列表没有目标模型怎么办？

展开完整列表并清除搜索条件，核对已获取数量。模型名可直接手填。服务如果没有返回某个模型，插件不能通过前端补出其权限；请检查服务账号与模型列表接口。

列表包含文字模型也不代表它们能图片生成。助手文字模型与工坊图片模型分别选择。

## OpenAI 兼容接口应该填到哪一级？

通常填服务根地址，例如 `https://example.com` 或 `https://example.com/v1/`，末尾斜杠可有可无。代理子路径要保留，生图路径在连接选项单独设置。查看请求预览，确认没有重复路径。

## OpenAI 格式里的 NAI 负面提示词填在哪？

模型名包含 `nai-diffusion` 时，独立负面提示词框自动出现。直接选择服务实际返回的完整模型名。普通图片模型不一定有原生负面参数。

## 刷新后 Key 看不到了？

先区分空值和密码遮罩：点击眼睛按钮查看，核对当前模式、命名接口、参数预设及账号。检查秘钥输入后的保存状态；修改命名接口后点击「保存当前接口」，修改预设后点击「保存预设」。

换设备、换浏览器或导入分享包后，凭据不一定存在。分享包不会带 Key，跨设备迁移需要含秘钥的加密备份。不要在问题截图里露出完整秘钥。

## ComfyUI 参数灰色、修改不生效？

展开节点映射，检查该参数是否对应 API 工作流里的正确节点。未映射会保留原工作流值；复杂多分支需要指定正确输入和输出。先在 ComfyUI 自己运行成功，再导入 API 格式 JSON。

## 图片始终没有出现在聊天里？

检查插件是否开启、图片接口是否可用、「在聊天中显示图片」是否开启、输出前后缀是否和设置一致。等待角色回复结束，不要用用户消息测试自动触发。

历史消息不自动补画，用「给这条配图」手动处理。生成成功但图片缺失时，核对存储位置以及原会话、消息和回复分支是否对应。

## 图生图和局部重绘为什么看起来相似？

两者都用底图，局部重绘还要编辑蒙版；图生图整体变化，局部重绘限制目标区域。只上传一张底图并不代表已经画好蒙版。参考 [高级生图](generation.md)。

## 智能配图为什么没有自动运行？

「自动生图」用于已有提示词标签；无标签剧情需要提示词助手的「自动准备配图提示词」。准备后是否自动出图还由另一个开关控制，默认都关闭。

核对文字接口、模型、输出 Token、配图频率与上下文。助手报错不会无限自动重试，可以先手动准备一条草稿。

## 为什么刷新后要手动继续任务？

未提交任务需要确认后继续，避免刷新触发重复生图。已返回图片可以继续保存；已提交但结果不明时先到服务端核对。详见 [任务恢复](gallery-tasks.md)。

## 浏览器模式和酒馆服务器模式图片数量不同？

两者是不同图库，切换不会自动搬迁。服务器存储页的迁移按钮可处理浏览器作品；先备份，再核对结果。清除浏览器站点数据可能删除浏览器作品和本地凭据。

## 远程接口报跨域、Mixed Content 或无法访问？

请求通常从浏览器发出，接口需允许酒馆站点访问。HTTPS 页面连接 HTTP 服务可能被浏览器拦截，应由管理员配置 HTTPS 入口和跨域。`127.0.0.1` 指当前浏览器所在电脑。

## 前端 0.21.1，服务器组件却显示 0.21.0？

0.21.1 只增加更新日志与文档，配套组件自身版本仍为 0.21.0，存储协议为 2，这是当前发行的正常组合。只有协议／能力不匹配或组件确实过旧时才需要处理。

## 手机找不到绘图管理或更新日志？

窄屏导航在上方横向滚动，向左滑动导航条即可看到后面的入口；也可以从「插件设置 → 版本与更新」打开更新日志。

## 更新后想回退怎么办？

从旧版 Releases 取对应代码，并恢复升级前同版本的配置备份。先保存当前需要的作品；不要假设旧代码能直接读取所有新配置。见 [安装与更新](install.md)。
